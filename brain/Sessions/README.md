# Sessions

Use this folder for lightweight human/agent session notes that are useful in Obsidian but do not belong in the canonical operational state.

Suggested filename:
`YYYY-MM-DD - <agent or topic>.md`

Material changes must also be summarized in `docs/agent-context/SESSION_LOG.md` and, when relevant, `CURRENT_STATE.md`.

Never store secrets, passwords, tokens, customer PII, or private credentials.
